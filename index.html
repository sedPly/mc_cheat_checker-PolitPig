📖 Документация





1. Установка











PowerShell





# Скачайте скрипт с сайта или создайте файл:



PS>
 Invoke-WebRequest -Uri "https://ВАШ_ЮЗЕР.github.io/REPO/generate-codes.ps1" -OutFile ".\generate-codes.ps1"



# Или создайте вручную:



PS>
 New-Item -Path ".\generate-codes.ps1" -ItemType File



# Скопируйте код скрипта из вкладки "PowerShell"











2. Размещение на GitHub Pages






1


Создайте репозиторий на GitHub (например: codegen)






2


Загрузите файлы: index.html, assets/ (из папки dist/ после сборки)






3


Загрузите generate-codes.ps1 в корень репозитория






4


Перейдите в Settings → Pages






5


Выберите Source: Deploy from a branch → main → / (root)






6


Ваш сайт будет доступен по адресу: https://ВАШ_ЮЗЕР.github.io/codegen/











3. Настройка PowerShell











PowerShell (Admin)





# Разрешить выполнение скриптов:



PS>
 Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser



# Запуск скрипта:



PS>
 .\generate-codes.ps1 -Type promo -Count 5












4. Связь PowerShell ↔ Сайт




PowerShell скрипт может взаимодействовать с сайтом несколькими способами:



→

Открыть сайт: Start-Process "https://ВАШ_ЮЗЕР.github.io/codegen/"





→

Скачать скрипт: Invoke-WebRequest -Uri "https://ВАШ_ЮЗЕР.github.io/codegen/generate-codes.ps1"





→

Генерация в PS: Скрипт генерирует коды локально без интернета





→

Экспорт: -Export -OutputPath ".\result.txt"
